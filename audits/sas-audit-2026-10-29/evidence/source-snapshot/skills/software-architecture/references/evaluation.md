# Captured quality, deterministic checks and research — 0.7

The evaluator reads supplied cases/responses and never calls a model. It validates fixture shapes/counts, runs bounded regex workers and direct max_chars/max_words/max_sentences predicates. Missing/timed-out responses are not passes. Report-only is default; explicit `--gate --min-pass 100` controls CI exit semantics. Sample responses are a harness self-test, not evidence of live architecture quality. A wrong keyword-stuffed answer can still pass lexical checks.

Use `capture --prompt FILE --response FILE --model REPORTED --output FILE` for actual caller-supplied response provenance. The tool records the skill hash/time/source and leaves semantic reviews empty. Report an unknown model honestly when the host does not expose it. Supply calibrated human assessments for correctness, evidence, risk handling, constraints and usefulness using evals/semantic-review-rubric.json. Preserve assessor disagreement, critical failures, missing cases and task/language/tool slices; repeat scoped runs before generalizing. `quality-summary` accounts for captures/reviews, not semantic truth. Never label templates or assistant-written examples as independently captured benchmark evidence.

Independent specialist review is selective and optional. Freeze sources, give clean first-pass contexts and wait for all first passes before peer review. Record actual agents, failures/restarts, shared biases, useful corrected findings and actual available cost/time. review-plan emits a protocol only. Hard token/tool/delegation limits require an actual mediating host; otherwise they are advisory/unsupported. Do not make ten agents the default.

research-kit is a structured user-research instrument for resume/change/handoff tasks, not completed interviews. Record observed task completion/corrections/time/trust/counterexamples with minimal aliases and consent. Do not claim market superiority, adoption, ROI or measured benefits until evidence exists. Hosted/index/multi-model expansion remains deferred pending that evidence.
