# Handoff compiler and readiness — 0.7

Compile from canonical context with `handoff ROOT --output OUT [--profile brief|draft|review-ready] [--dry-run]`. Plans validate before writes. The package includes architecture, requirements/acceptance, supported detailed OpenAPI, all interface contracts, data schemas, tasks/AC, ADRs, traceability, diagram source/alias map, security gaps, risks and a readiness/report manifest. Native `api_contract` is retained; `interface.operation` supports detailed operations. Duplicate method/path/operation IDs are errors. All eight OAS verbs are supported. Non-HTTP interfaces remain in contracts.json with explicit applicability; AsyncAPI is passed through when actually supplied. Raw migration SQL is never executed. `data-check` tests allowlisted structured SQLite columns in memory only.

Profiles specify applicable completeness obligations. Drafts may contain labeled placeholders. Review-ready blocks unresolved applicable requirements. Completeness, structure/correspondence, human review, runtime verification and freshness are independent; waived-with-reason is not passed. Unknown auth is an unresolved decision, not invented public/protected behavior.

The compiler uses safe aliases for canonical IDs; component association order cannot invent flow direction. Every supported record has output coverage or an exact diagnostic. Immutable generations are published through an atomic `.handoff-current.json` pointer. Readers must use returned `read_path`/`resolve_generation` for coherent artifacts. Direct legacy projections may be incomplete after failure; `handoff-recover OUT` repairs only unchanged owned paths and preserves human edits. Stale managed ADRs are removed under ownership/hash checks; unrelated files are not called generated. No universal multi-file atomicity/durability claim is made.

Default disclosure omits opaque root extensions/private history and redacts obvious credential values; detection is incomplete. `--include-private` is a deliberate full canonical backup. Review before sharing. Inspect actual `validate` results separately; compilation does not perform a deployment, semantic review, full OAS validation or real diagram render automatically.
