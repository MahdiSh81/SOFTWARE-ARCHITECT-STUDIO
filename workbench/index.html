Handoff & checks
This browser validates canonical structure and links. It does not run a repository scan, real Mermaid renderer, full OpenAPI validator, model evaluation, or deployment. Use the local CLI for artifact generation and exact gate reports.
Three outcome journeys
  1. Focused decision: answer a narrow question at the requested depth; project files are optional.
  2. Resume / change: import canonical context, inspect accepted choices, apply a small validated edit and save a revision.
  3. Handoff / review: export the portable context, compile a scoped package and inspect readiness and actual checks.
Move this project to the CLI
Export portable project, create a directory such as my-project, and save the download inside it as project.json. Run these commands from the Software Architect Studio checkout. Keep the original download or a private backup before editing. Output depth is separate from the handoff profile.
python tools/architect_cli.py resume ./my-project
python tools/architect_cli.py handoff ./my-project --output ./handoff --profile draft --dry-run
python tools/architect_cli.py handoff ./my-project --output ./handoff --profile draft
python tools/architect_cli.py validate ./handoff --gate structural

Completeness, structural checks, human review and runtime verification are independent. A missing required gate is not a passed gate. Hosted projects, universal indexing and multi-model deployment remain deferred.
